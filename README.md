## 知识点概览

| # | 知识点 | 一句话总结 |
|---|--------|-----------|
| 1 | **核心公式** | Agent = LLM(大脑) + 上下文(眼睛) + 工具(手脚)，三者缺一不可 |
| 2 | **ReAct循环** | 思考→行动→观察不断重复，上下文=静态前缀+轨迹 |
| 3 | **上下文五组件** | 消融实验证明每个组件不可替代 |
| 4 | **Harness工程** | 模型之外=竞争力所在，五要素闭环 |
| 5 | **编排模式** | 工作流(确定性) vs 自主(动态)，从简单到复杂 |
| 6 | **人工干预** | 两种触发：超过失败阈值 + 高风险操作 |
