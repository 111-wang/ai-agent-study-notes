01 Agent 核心公式

Agent = LLM + 上下文 + 工具
= 大脑 + 眼睛 + 手脚

三大组件的广义理解

组件比喻广义含义
LLM🧠 大脑整个决策内核——理解意图、思考规划、做出判断。能力来自预训练的世界知识 + 后训练的决策策略
上下文👁 眼睛每个决策点能看到的全部信息——环境、记忆、知识、自身状态和任务进展
工具🤲 手脚能做的所有事——预定义工具调用、按需加载技能(Skills)、动态生成代码、委托子Agent、与用户沟通
💡 关键洞察

观察空间 + 动作空间 = LLM 与外部世界的接口。模型固定时，提升 Agent 能力最有效的手段就是扩展这两个空间。

02 ReAct 循环

循环
上下文 = 静态前缀(系统提示词 + 工具定义) + 轨迹(消息 + 回复 + 工具结果)

上下文的累积性

每次调用 LLM 都能看到完整轨迹——之前所有的消息、回复和工具结果，这让 Agent 知道"我现在做到哪了"。轨迹持续增长，不会丢失。

📌 实例

多币种收入汇总：第1轮并行调用3个货币转换工具 → 第2轮调用代码解释器计算 → 第3轮输出最终答案。仅3次迭代、4次工具调用。

03 上下文五组件与消融实验

像医生逐一排除病因一样，每次去掉一个组件看系统是否还正常。

#组件去掉后的影响严重程度
1系统提示词失去角色定位和基本行为准则中等
2工具定义不知道有哪些工具可用，完全丧失行动能力严重
3思考过程前后决策互相矛盾，丧失思维连贯性中等
4历史消息失忆，从头开始整个任务，重复已完成步骤严重
5工具结果看不到上一步反馈，反复调用同一工具，陷入无限循环严重
💡 核心洞察

上下文决定 Agent 能看到什么，而 Agent 只能基于看到的信息做决策。信息缺失 → 决策缺陷，这是因果链的铁律。

04 Harness 工程

Harness = 模型之外的所有工程实践，是整章最重要的概念转折。

层要素说明
1上下文什么时候给模型看什么信息
2工具给模型哪些能力，约束怎么调
3约束防止模型做不该做的事
4验证模型做完后如何检查结果是否正确
5纠正检查发现问题时如何修复

五要素形成闭环：上下文 → 工具 → 约束 → 验证 → 纠正 → 回到上下文

🔥 关键判断

当各家模型能力越来越接近，竞争优势就转移到了模型之外的工程实践。实证：LangChain 在 Terminal Bench 2.0 上从 52.8% → 66.5%，改变的不是模型，而是 Harness。

05 编排模式：工作流 vs 自主 Agent

维度工作流 (Workflow)自主 Agent (Autonomous)
决策方式确定性路由，预定义步骤LLM 动态决策，灵活选择路径
可靠性高 可控可预测低 存在幻觉和偏离风险
灵活性低 难以处理未预见情况高 能应对新颖场景
适用场景合规流程、标准操作探索性任务、复杂决策
调试难度低，路径明确高，行为不可预测
🎯 核心原则

从简单到复杂：先优化提示词 → 再考虑工作流 → 最后才引入自主 Agent。如果优化提示和上下文示例就能解决，就别引入 Agent 系统。

实践中两种模式常常混合使用：关键合规流程用工作流保证可靠性，灵活决策部分切换到自主模式。

06 人工干预：Human in the Loop

人工干预是 Agent 安全运行的最后一道防线——让 Agent "在无法完成时优雅地转移控制权"。

触发条件说明示例
超过失败阈值重试次数设上限，多次尝试仍无法理解意图 → 升级人工用户意图模糊，Agent反复理解失败
高风险操作敏感、不可逆的操作 → 必须人工确认取消订单、大额退款、付款审批

部署早期的特殊价值

  • 识别失败模式 — 哪些场景 Agent 容易出错
  • 发现边缘情况 — 训练数据没覆盖的特殊场景
  • 建立评估周期 — 逐步量化 Agent 的可靠度

设计原则

  • 设定明确的重试上限（如3次），超过即升级人工
  • 对不可逆操作强制人工确认
  • 保留完整的决策轨迹，方便人工快速理解上下文
  • 随着系统成熟，逐步收窄人工干预范围

🎯 全章总结

#知识点一句话总结
1核心公式Agent = LLM(大脑) + 上下文(眼睛) + 工具(手脚)，三者缺一不可
2ReAct循环思考→行动→观察不断重复，上下文=静态前缀+轨迹(累积增长)
3上下文五组件消融实验证明每个组件不可替代，上下文决定Agent能看到什么
4Harness工程模型之外=竞争力所在，五要素闭环：上下文+工具+约束+验证+纠正
5编排模式工作流(确定性) vs 自主(动态)，从简单到复杂，可混合使用
6人工干预两种触发：超过失败阈值 + 高风险操作，优雅移交控制权
💎 终极洞察

模型还做不稳的，Harness 先补上；模型每内化一层，Harness 就卸下一层，转而兜底新的能力前沿。此刻模型的能力边界，就是 Harness 此刻的价值所在。
